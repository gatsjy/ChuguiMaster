# 💍 ChuguiMaster (축의금 스마트 자동 취합 & 감사 메시지 생성기)

> **"축의금 취합부터 하객 감사 메시지 1초 발송까지, 최소한의 노력으로 가장 완벽하게!"**
> 
> ChuguiMaster는 결혼식 및 경조사 후 수기로 일일이 정리하던 축의금 내역을 카톡/메모장 복사-붙여넣기만으로 자동 파싱하고, 계좌이체 내역 통합, 식대 자동 차감 결산, 그리고 **하객별 맞춤 감사 메시지 1초 복사/발송**까지 지원하는 윈도우 전용 데스크톱 프로그램입니다.

---

## 🌟 주요 핵심 기능

### 1. ⚡ 1초 복사-붙여넣기 스마트 자동 파싱
* 양식에 맞추어 하나씩 입력할 필요가 없습니다.
* 카톡이나 메모장에 작성된 자유로운 형식의 글을 그대로 복사하여 붙여넣으면, 알고리즘이 알아서 **[이름 / 금액 / 관계 / 식권 수량]**을 분리하여 깔끔한 표로 변환합니다.
  * 예시 입력: `홍길동 10만원 직장 식권2`, `김철수 50,000 대학`, `이영희 10만 친척 (불참)`
  * 결과: 4개의 독립 컬럼으로 자동 구분 및 금액 표준화

### 2. 🏦 현금 수령 + 계좌이체/모바일 송금 내역 원클릭 통합
* 현금 봉투 내역과 은행/토스/카카오뱅크 입금 내역(엑셀)을 드래그 & 드롭으로 합쳐서 **누락 없는 총 축의금**을 집계합니다.

### 3. ✉️ 맞춤형 감사 메시지 자동 생성 & 원클릭 복사 (`📋`)
* 하객의 **[관계]**(상사, 동료, 친구, 친척)와 **[참석 여부]**(직접 참석, 불참 후 송금)에 따른 톤앤매너별 감사 문구를 자동으로 생성합니다.
* **`[📋 1초 복사]`** 버튼 클릭 한 번으로 문구가 클립보드에 복사되며, 카카오톡/문자 입력창에 `Ctrl + V` 후 바로 발송할 수 있습니다.
* **`[☑ 발송 완료]`** 체크박스로 감사 인사를 놓친 하객이 없도록 100% 추적 관리합니다.

### 4. 📊 식대 차감 및 최종 순 정산금 계산기
* `총 축의금 - (식대 × 발급된 식권 수) = 최종 순 정산 금액`을 실시간으로 계산하여 이번 경조사의 손익을 한눈에 파악합니다.

### 5. 📥 엑셀(Excel) 내보내기 & 영구 보관
* 취합된 모든 데이터와 감사 인사 발송 여부를 깔끔한 엑셀 파일(`.xlsx`)로 저장할 수 있습니다.

## 💡 축의금을 가장 쉽게 취합하는 3단계 실전 가이드

1. **[1단계] 현금 & 계좌 내역 수집**
   * 현금 봉투는 메모장이나 카톡에 `이름 금액 관계` 형식으로 편하게 적어둡니다.
   * 계좌이체 내역은 해당 은행 앱에서 엑셀 파일로 다운로드합니다.
2. **[2단계] ChuguiMaster 프로그램으로 1초 취합**
   * ChuguiMaster를 실행하고 텍스트를 복사-붙여넣기하거나 엑셀 파일을 끌어옵니다.
   * `[⚡ 자동 취합 및 파싱]` 버튼을 누르면 전체 리스트와 총액이 정산됩니다.
3. **[3단계] 감사 메시지 원클릭 복사 및 발송**
   * 리스트 옆의 `[📋 인사말 복사]` 버튼을 눌러 카카오톡이나 문자 입력창에 `Ctrl + V`로 바로 전송합니다.
   * 전송 후 `[☑]` 체크박스를 활성화해 완벽하게 발송 관리를 마칩니다.

| :--- | :--- | :--- | :--- |
| **홍길동** | 직장 상사 | 참석 | `홍길동 팀장님, 바쁘신 와중에 저희 결혼식에 참석하여 자리를 빛내주셔서 진심으로 감사드립니다. 보내주신 축복 잊지 않고 행복하게 잘 살겠습니다.` |
| **김철수** | 대학 친구 | 참석 | `철수야! 멀리서 와줘서 진짜 고맙다! 덕분에 너무 든든했어. 신혼여행 다녀와서 조만간 맛있는 거 쏠게!` |

## 🛠️ 프로그램 구조 및 기술 스택

* **GUI Framework**: Python `PySide6` (Qt for Python)
* **Data Processing Engine**: `pandas`, `openpyxl`, `re` (정규식 파서)
* **Executable Packaging**: `PyInstaller` (단일 `.exe` 실행 파일 생성)

### 디렉토리 구조
```text
ChuguiMaster/
├── README.md                 # 프로젝트 종합 안내서
├── build.py                  # PyInstaller executable 빌드 스크립트
└── src/
    ├── smart_parser.py       # 자유 텍스트 / 엑셀 자동 파싱 모듈
    ├── message_generator.py  # 맞춤형 감사 메시지 자동 생성 모듈
    └── ui/
        └── main_view.py      # PySide6 기반 UI 메인 뷰
```

---

## 🚀 실행 방법 (사용자용)

1. 배포된 `ChuguiMaster.exe` 실행 파일을 다운로드합니다.
2. 실행 후 텍스트 붙여넣기 또는 엑셀 파일을 드래그하여 축의금을 자동 취합합니다.
3. 감사 메시지 복사 버튼으로 카카오톡/문자 발송을 완료합니다.

---

## 💻 빌드 방법 (개발자용)

```bash
# 1. 의존성 패키지 설치
pip install PySide6 pandas openpyxl pyinstaller

# 2. EXE 실행 파일 빌드
python build.py
```
빌드가 완료되면 `dist/ChuguiMaster.exe` 파일이 생성됩니다.
