# ChuguiMaster

**축의금 취합부터 하객 감사 메시지 발송까지, 한 화면에서.**

카톡·메모장에 적어둔 자유 형식 축의금 명단을 붙여넣으면 이름·금액·관계·식권 수를 자동으로 분리하고,
은행 계좌이체 내역(엑셀/CSV)을 합쳐 누락 없이 집계한 뒤,
하객별 맞춤 감사 메시지를 만들어 클립보드로 복사해 줍니다.

Windows 데스크톱 프로그램. Python + PySide6.

---

## 핵심 기능

### 1. 자유 텍스트 자동 파싱

양식을 맞출 필요 없이 붙여넣기만 하면 됩니다.

```
1 홍길동 200,000 친척모임
5 최동료 100,000 A보건지소 식권2
11 김가족,김친지 300,000 이모
17 추대리 10만 지인모임 불참
25 김성도(조성도) 50,000 OO교회
```

인식되는 것들:

| 항목 | 지원 표기 |
|---|---|
| 금액 | `100000` · `100,000` · `10만` · `10만원` · `10만 5천` · `3억 2천만` |
| 복수 이름 | `김가족,김친지` · `진부부·신부부` → 식권 2장으로 자동 계산 |
| 별칭 | `김성도(조성도)` → 괄호 안은 별칭으로 분리 |
| 식권 | `식권2` · `대인2` · `소인1` · `어린이1` |
| 참석 여부 | `불참` · `미참석` · `못 와서` · `송금` |
| 수령 경로 | `계좌` · `이체` · `송금` · `토스` · `카뱅` |
| 관계 | 친척/가족 · 직장/기관 · 종교/모임 · 학교/동창 · 지인/기타 |

**줄 앞의 번호, 식권 수, 날짜, 전화번호, 계좌번호는 금액에서 자동으로 제외됩니다.**

### 2. 확신하지 못하면 표시합니다

파서가 금액이나 이름을 확정하지 못하면 **조용히 추측하지 않고** `⚠ 확인 필요` 로 표시합니다.
상단 카드에 건수가 뜨고, `확인 필요만` 필터로 해당 행만 모아 볼 수 있습니다.

예를 들어 단위 없는 `500` 은 5만원인지 500원인지 알 수 없으므로 0원 + 경고로 남깁니다.
표에서 더블클릭해 직접 고치면 경고가 사라지고 즉시 저장됩니다.

### 3. 현금 + 계좌이체 통합

텍스트로 현금 명단을 취합한 뒤 은행 엑셀이나 CSV를 끌어다 놓으면 **기존 목록에 합쳐집니다.**
토스·카카오뱅크·시중은행 내역처럼 상단에 계좌·조회기간 안내가 붙은 파일도
헤더 행을 자동으로 찾아 읽습니다.

같은 이름이 양쪽에 있으면 지우지 않고 `중복 의심` 으로 표시합니다.
동명이인인지 중복 기입인지는 사람만 판단할 수 있기 때문입니다.

### 4. 식대 차감 정산

```
총 식대     = 대인 식권 수 × 대인 단가 + 소인 식권 수 × 소인 단가
최종 순정산 = 총 축의금 − 총 식대
```

불참(송금) 하객은 식권이 0장이므로 자동으로 제외됩니다.

### 5. 감사 메시지 생성 & 복사

관계와 참석 여부에 따라 문구가 달라집니다.

| 하객 | 관계 | 참석 | 생성 문구 |
|---|---|---|---|
| 홍길동 | 직장/기관 | 참석 | 홍길동님, 귀한 시간 내어 함께해주셔서 감사합니다. 축하해주신 마음 잊지 않고, 좋은 모습으로 보답하겠습니다. |
| 김철수 | 학교/동창 | 참석 | 김철수, 와줘서 정말 고마웠어. 바쁜 거 아는데 시간 내준 마음이 더 크게 느껴지더라. 조만간 얼굴 보자. |
| 이영희 | 학교/동창 | 불참(송금) | 이영희, 마음 보내줘서 고마워. 못 봐서 아쉬웠지만 축하해주는 마음 잘 받았어. 조만간 따로 보자. |
| 박이모 | 친척/가족 | 참석 | 박이모님, 저희 결혼식에 와주셔서 진심으로 감사했습니다. 그 자리에 계셔주신 것만으로 큰 힘이 되었어요. 주신 마음 잘 간직하며 살겠습니다. |

`[복사]` 버튼을 누르면 클립보드에 담기고, 카톡·문자에 `Ctrl+V` 로 붙여넣으면 됩니다.
**복사와 발송은 별개입니다** — 실제로 보낸 뒤 `발송` 을 직접 체크하세요.

문구는 `인사말 템플릿` 에서 관계 × 상황별로 자유롭게 수정할 수 있고,
`{name}` `{relation}` `{amount}` `{belong}` 자리표시자를 쓸 수 있습니다.

### 6. 엑셀 내보내기

`축의금 명단` 시트(헤더 고정 · 자동 필터 · 확인 필요 행 강조)와
`정산 요약` 시트가 함께 저장됩니다.

### 7. 실시간 자동 저장

작업 내용은 사용자 데이터 폴더에 자동 저장되고 다음 실행 시 복구됩니다.
저장은 **임시 파일 교체 방식**이라 저장 도중 프로그램이 종료돼도 파일이 깨지지 않으며,
직전 정상본을 백업으로 두고 손상 시 자동 복구합니다.

## 사용법

1. 카톡·메모장에 `이름 금액 소속` 형식으로 편하게 적어둡니다.
2. ChuguiMaster에 붙여넣고 `자동 취합 및 파싱`(`Ctrl+Enter`).
3. 은행 앱에서 받은 계좌이체 엑셀을 창에 끌어다 놓아 합칩니다.
4. `⚠ 확인 필요` 행이 있으면 값을 확인·수정합니다.
5. `[복사]` → 카톡에 붙여넣기 → 발송 → `발송` 체크.
6. `Ctrl+S` 로 엑셀 저장.

**단축키**: `Ctrl+Enter` 파싱 · `Ctrl+S` 내보내기 · `Ctrl+F` 검색

## 설치 및 실행

### 사용자

배포된 `ChuguiMaster.exe` 를 실행하면 됩니다.

### 개발자

```bash
pip install -r requirements.txt
python main.py
```

테스트:

```bash
pip install -r requirements-dev.txt
python -m pytest
```

빌드:

```bash
python build.py
```

`dist/ChuguiMaster/ChuguiMaster.exe` 가 생성됩니다.
단일 파일이 필요하면 `python build.py --onefile` (기동은 느려집니다).

## 기술 스택

| 항목 | 사용 |
|---|---|
| GUI | PySide6 (Qt for Python), Model/View 아키텍처 |
| 스프레드시트 | openpyxl |
| 패키징 | PyInstaller |
| 테스트 | pytest (211개) |
| 린트 | ruff |

> **pandas를 쓰지 않습니다.** 이 프로그램이 pandas에서 필요로 한 기능은
> `read_excel` / `to_excel` 두 개뿐인데, 그 대가로 실행 파일이 두 배가 되고
> 콜드 스타트가 몇 초씩 늘어납니다. openpyxl로 충분합니다.

## v2.0.0 변경 사항

전체 이력은 [CHANGELOG.md](CHANGELOG.md), 내부 동작은 [FLOW.md](FLOW.md)를 참고하세요.

v1의 정산 신뢰성 문제를 해결하기 위한 전면 재작성입니다.

**정확도**
- 금액 파서 재작성 — v1은 줄 전체의 숫자를 이어붙여 `1 홍길동 200000` 을 **1,200,000원**으로 계산했습니다(6배). 내장 샘플 데이터 전체가 틀린 금액이었습니다.
- 정산식을 명세대로 수정 — v1은 `하객 수 × 대인 단가` 로 계산해 식권 수와 소인 단가를 전혀 쓰지 않았고, 불참 하객에게도 식대를 차감했습니다.
- 이름 추출 재작성 — v1은 글자 단위 삭제 방식이라 `이체리` `권원식` 같은 실명이 사라졌습니다.
- 관계 분류를 최장 일치 방식으로 변경.

**안정성**
- 첫 실행 크래시 3건 수정(부분 세션 레코드 · CSV · 사용자 템플릿의 중괄호).
- 원자적 저장 + 백업 자동 복구.
- 표 편집이 조용히 사라지던 문제 수정.
- 토스트가 두 번째부터 즉시 사라지던 문제 수정.
- 관계 변경 시 발생하던 재진입 크래시 위험 제거.
- 기본 정렬이 역순으로 표시되던 문제 수정.

**기능**
- 현금 + 계좌이체 병합 구현(v1에는 없었습니다).
- 은행 엑셀 헤더 자동 탐색, CSV 실제 지원.
- `⚠ 확인 필요` 표시 및 필터.
- 표 직접 편집, 전체 열 정렬, 미발송 필터.
- 엑셀 내보내기에 서식과 정산 요약 시트 추가.

**구조**
- 939줄 God object를 계층 분리된 패키지로 분해.
- 테스트 0개 → 211개.
- 설정/세션을 OS 표준 사용자 데이터 폴더로 이전.
- 파일 로깅 도입.
- pandas 제거.
- 저장소에 커밋돼 있던 사용자 데이터 파일과 소스에 하드코딩된 실명 제거.
