# 📖 축의금 마스터 (ChuguiMaster v2.1.0)

카카오톡, 메모장 텍스트 및 엑셀 파일 형태의 하객 축의금 명단을 규칙 기반 스마트 파서로 취합하고, 식대 정산과 맞춤 감사 인사말 복사를 지원하는 데스크톱 프로그램입니다.

---

## ⚡ 1초 무설치 실행 방법 (비개발자용 초간단 안내)

배포된 실행 파일이 있다면 컴퓨터에 파이썬을 설치하지 않고 실행할 수 있습니다.

### 💻 일반 사용자 실행 (추천 🌟)
1. 배포받은 `ChuguiMaster` 폴더의 압축을 풉니다.
2. 폴더 안의 **`ChuguiMaster.exe`**를 더블 클릭합니다.
3. 단일 파일 배포본은 **`ChuguiMaster.exe`** 하나만 실행하면 됩니다.

---

## 1. 📊 한눈에 보는 컴팩트 스마트 대시보드

![메인 대시보드 스크린샷](docs/images/dashboard.png)

### 💡 주요 기능
- **총 수령 축의금**: 수령한 총 금액과 현금/계좌이체 수령액을 실시간 집계합니다.
- **하객 통계**: 총 등록 건수, 실제 방문 인원, 참석 및 불참 하객 수를 한눈에 계산합니다.
- **총 식대**: 대인/소인 식권 발급 수량에 맞춰 총 식대를 자동으로 산출합니다.
- **최종 순 정산금**: `총 수령 축의금 − 총 식대`를 차감하여 실제 남은 순 정산금을 직관적으로 보여줍니다.

---

## 2. 🍽️ 실시간 식대 단가 설정 및 자동 재계산

![식대 단가 설정 스크린샷](docs/images/meal_cost.png)

### 💡 주요 기능
- **단가 자유 변경**: 대인(성인) 식대 단가와 소인(어린이) 식대 단가를 자유롭게 조정할 수 있습니다.
- **즉시 실시간 반영**: 화살표 버튼 클릭 및 숫자 직접 입력 후 Enter 키를 누르는 즉시 상단 대시보드의 **총 식대** 및 **최종 순 정산금**이 0.1초 만에 자동 계산됩니다.
- **자동 저장**: 설정한 식대 단가는 프로그램 종료 후 다시 실행해도 이전 설정값이 자동으로 유지됩니다.

---

## 3. 🏷️ 하객 명단 관리 및 드롭다운 카테고리 태그

![하객 명단 테이블 스크린샷](docs/images/table.png)

### 💡 주요 기능
- **드롭다운 카테고리 태그**: 관계 태그(`친척`, `친구`, `직장`, `교회`, `기타`)를 클릭하여 손쉽게 변경할 수 있습니다.
- **카테고리 변경 시 즉시 갱신**: 관계를 변경하면 하객의 맞춤 감사 인사말 템플릿과 스타일 태그가 즉시 변경됩니다.
- **다크 모드 가독성 지원**: 어두운 테마에서도 모든 하객의 이름과 금액 텍스트가 시원하고 선명하게 표현됩니다.

---

## 4. 💬 감사 인사말 1초 클립보드 복사

### 💡 주요 기능
- **1초 복사 버튼**: 각 하객 행의 `[📋 복사]` 버튼을 누르면 맞춤 감사 인사말이 클립보드에 복사됩니다.
- **예시 메세지**:
  > *"홍길동님, 저희 결혼식에 와주셔서 진심으로 감사했습니다. 그 자리에 계셔주신 것만으로 큰 힘이 되었어요. 주신 마음 잘 간직하며 살겠습니다."*
- **카카오톡/문자 즉시 발송**: 복사 후 카카오톡 채팅창이나 문자 메시지창에 `Ctrl+V`로 붙여넣어 바로 발송할 수 있습니다.

---

## 5. ✍️ 표 붙여넣기 & 실시간 미리보기

### 💡 주요 기능
- **엑셀 표 그대로 붙여넣기**: `이름 / 금액 / 소속` 열을 탭이나 공백으로 구분해 붙여넣으면 열을 그대로 인식합니다. 소속에 숫자가 섞여 있어도 금액이 흔들리지 않습니다.
- **실시간 미리보기**: 입력창 아래에 `미리보기 · 225건 · 28,470,000원 · 확인 필요 2건` 처럼 결과가 바로 뜹니다. 파싱 버튼을 누르기 전에 확인할 수 있습니다.
- **추가 모드**: `기존 목록에 추가`(`Ctrl+Shift+Enter`)로 기존 명단을 지우지 않고 새 줄만 이어붙입니다.

---

## 6. 💾 자동 저장 & 실수 복구

### 💡 주요 기능
- **자동 저장**: 명단을 입력하거나 수정하면 별도 저장 버튼 없이 사용자 데이터 폴더에 보관됩니다. 임시 파일 교체 방식이라 저장 도중 꺼져도 파일이 깨지지 않습니다.
- **갑작스러운 종료 후 복구**: 다시 실행하면 마지막 상태를 불러오며, 주 파일이 손상되면 직전 백업본을 사용합니다.
- **비정상 종료 알림**: 지난번에 강제 종료되었다면 그 사실과 복구 건수를 알려 줍니다.
- **되돌리기 버튼**: `전체 비우기`·덮어쓰기·병합 직후 토스트의 `되돌리기`를 누르면 그대로 복구됩니다.
- **이전 시점 복구**: 파괴적인 작업 직전과 5분마다 시점이 자동 저장됩니다. `이전 시점 복구` 버튼에서 시각·건수·총액을 보고 골라 되돌립니다.
- **셀 편집 되돌리기**: 표에서 값을 잘못 고쳤다면 `Ctrl+Z`, 다시 하려면 `Ctrl+Y`.

## 🛠️ 개발자용 실행 및 빌드 안내

### 소스 코드 직접 실행 (Python 3.10+)
```bash
# 1. 필수 라이브러리 설치
pip install -r requirements.txt

# 2. 프로그램 실행
python main.py
```

### 포터블 단일 실행 파일 (.exe) 직접 빌드
```bash
python build.py --onefile
```
* 빌드 완료 후 **`dist/ChuguiMaster.exe`** 파일이 생성됩니다.

빠른 실행이 중요한 폴더형 배포본은 `python build.py`로 만들며,
실행 파일은 **`dist/ChuguiMaster/ChuguiMaster.exe`**에 생성됩니다.
